# Customer Segmentation & Reinforcement Learning

A practical exploration of Unsupervised Learning and Reinforcement Learning using Python, with business-oriented applications in customer analytics and delivery route optimization.

## 📌 Project Overview

This project demonstrates how machine learning can support business decision-making through two practical applications:

1. Customer Segmentation using K-Means Clustering
2. Reinforcement Learning concepts using a delivery-route example

The project focuses on understanding customer behaviour, identifying patterns in data, and learning how intelligent systems make decisions using rewards and feedback.

## 🎯 Objectives

- Understand the fundamentals of Unsupervised Learning.
- Implement K-Means Clustering for customer segmentation.
- Identify customer groups based on spending and app activity.
- Interpret machine learning results from a business perspective.
- Understand the basic concepts of Reinforcement Learning.
- Explore the relationship between agents, actions, and rewards.
- Understand exploration and exploitation in decision-making.

## 📊 Part A: Customer Segmentation

### Business Problem

An online retailer wants to understand different types of customers.

The dataset contains:

- Customer ID
- Monthly Spending
- App Visits

K-Means Clustering is used to divide customers into three groups based on their spending and app activity.

### Business Applications

Customer segmentation can help businesses with:

- Personalized marketing campaigns
- Customer loyalty programs
- Targeted recommendations
- Customer engagement strategies
- Re-engagement campaigns

### Machine Learning Approach

1. Create a customer dataset.
2. Select relevant features.
3. Apply K-Means Clustering.
4. Assign customers to clusters.
5. Visualize the customer groups.
6. Interpret the clusters from a business perspective.

## 🚚 Part B: Reinforcement Learning

### Business Problem

A delivery company has two possible routes:

- Route A
- Route B

The company wants to understand how a decision-making system can select routes based on delivery performance.

A simple reward-based example is used to introduce the concepts of Reinforcement Learning.

### Key Concepts

| Concept | Example |
|---|---|
| Agent | Delivery decision system |
| Environment | Roads and traffic |
| Action | Choosing a delivery route |
| Reward | Feedback based on delivery performance |

### Exploration vs Exploitation

**Exploration:** Trying a new or less-used option to learn more about it.

**Exploitation:** Choosing an option that is already known to perform well.

### Business Applications

Reinforcement Learning can be explored in areas such as:

- Route optimization
- Logistics and supply chain
- Dynamic decision-making
- Resource allocation
- Recommendation systems

## 📈 Results and Learning Outcomes

Through this practical, we explored:

- How K-Means groups customers with similar characteristics.
- How customer data can support marketing decisions.

## ⚠️ Project Limitations

- The customer dataset is small and created for educational purposes.
- Only two customer features are used for clustering.
- The route example uses predefined rewards.
- The reinforcement learning section introduces basic concepts rather than training a complete reinforcement learning model.
- Results may differ when using real-world business data.
